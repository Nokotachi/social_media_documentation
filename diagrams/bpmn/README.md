# BPMN-диаграммы

 `post_publication.bpmn` | Публикация поста 
 `feed_for_you.bpmn` | Формирование ленты «Для вас» 

Диаграммы намеренно упрощены до бизнес-уровня: без технических деталей вроде
TTL токенов, статусов БД, таймаутов ожидания ответа от сервисов. Технический
протокол взаимодействия сервисов (запросы, таймауты, повторные попытки) будет
описан отдельно, в UML Sequence диаграммах.
